1. Цель и задачи работы

Цель: разработать учебное приложение, имитирующее работу клиент-банка (по образцу мобильных/веб-приложений банков), демонстрирующее основные принципы построения подобных систем: хранение счетов и карт клиента, перевод средств между счетами, ведение истории операций.

Задачи:

  • спроектировать структуру данных для хранения пользователей, счетов, карт и операций;
  • реализовать генерацию тестовых данных (фамилии, имена, номера карт, начальные балансы);
  • реализовать вход в систему, просмотр счетов и карт, историю операций;
  • реализовать перевод средств между счетами с проверкой достаточности баланса;
  • оформить интерфейс, приближенный по виду к реальным банковским приложениям.

2. Используемые технологии

HTML5, CSS3, JavaScript (ES6). Приложение полностью самодостаточно: не требует установки, сервера или подключения к интернету — открывается одним файлом в любом современном браузере.

Честно о реализации: хранение данных выполнено в оперативной памяти браузера (структуры данных JavaScript), а не во внешней базе данных (SQL/файловой) — это сознательное упрощение для демонстрационной версии курсовой работы. Логически структуры данных ниже (пользователи, счета, карты, операции) построены так же, как были бы устроены таблицы в настоящей базе данных, включая связи между ними по идентификаторам.

3. Генерация тестовых данных

При каждой загрузке страницы генерируется новый набор из пяти пользователей со случайными русскими фамилиями и именами, у каждого — один или два счёта, к каждому счёту привязана карта. Номер карты — 16 цифр, соответствует контрольному алгоритму Луна (используется в реальных платёжных системах для проверки корректности номера), но начинается с заведомо не выданной комбинации цифр (9999), чтобы номер ни при каких обстоятельствах не совпал с настоящей картой действующей платёжной системы.
